# Лёгкий старт — мини-приложение академии Whieda

10-дневная программа адаптации новичков до статуса бизнес-партнёра.

## Что это за папка

Это «дом», в котором будет жить код приложения. Сейчас заложен **фундамент** —
модель данных (описание того, что приложение хранит).

## Два входа в одно приложение

- **Основной — браузер:** ссылка вида `app.whieda.ru` открывается везде,
  без мессенджеров.
- **Дополнительный — Telegram-бот:** второй, необязательный вход + напоминания.

Оба входа ведут в один кабинет ученика, связка по email/телефону с оплаты GetCourse.

## Роли (уровни)

Новичок → Директор → Национальный директор (+ Куратор — курирует прохождение).

## Где что лежит

| Папка/файл | Что это |
|---|---|
| `prisma/schema.prisma` | **Модель данных** — главный чертёж: что и как хранится |
| `.gitignore` | Список того, что НЕ хранить в GitHub (мусор, секреты) |
| `package.json` | «Паспорт» проекта |

## Технологии (стек)

- **Frontend** (экраны): React + Telegram Web App SDK
- **Backend** (логика): Node.js
- **База данных:** PostgreSQL + Prisma
- **Хостинг:** Timeweb Cloud (РФ, 152-ФЗ)
