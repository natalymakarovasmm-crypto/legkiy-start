## 1. Что это за проект
Мини-приложение для 10-дневной программы адаптации новичков «Лёгкий старт».
Иерархия: **Новичок → Директор → Национальный директор** (+ **Организатор** = админ/владелец, видит всё).
Геймификация — баллы «Драконы». Есть программа по дням, личный чат, рейтинги.

## 2. Технологии и архитектура
- **Backend:** Node.js (v24) + Express — один файл `src/server.js`. Точка входа `index.js` (require src/server.js).
- **Frontend:** одностраничное приложение `public/index.html` (обычный JS, без фреймворков). Картинки в `public/assets/`.
- **Хранение:** массивы в памяти (`users`, `submissions`, `messages`) + сохранение в `data/app-data.json` (загрузка при старте, `saveData()` после изменений). Картинки чата → `public/uploads/`.
- **Сборки нет.** Запуск: `npm start` (= `node src/server.js`). Слушает `0.0.0.0` и `process.env.PORT || 3000`.
- Зависимость одна: `express`.

## 6. Что СДЕЛАНО
- 3 роли + кабинет Организатора; рефералка (у Национального 2 ссылки, у Директора 1, у Новичка нет).
- Программа Дни 0–10: миссии новичка + чек-листы директора; открытие по «общему старту» и часу.
- Драконы: звонок +5 (авто), проведённая встреча +50 (подтв. директором), сделка +100 (подтв.), итоги дня +10 (авто).
- Новичок вводит цифры дня («Подведение итогов») → директор в «Проверке» **подтверждает и может исправить** цифры → начисляются Драконы.
- 3 рейтинга (новичков/директоров) + **рейтинг команд** (виден всем).
- Кабинет **Организатора**: вся статистика по всем командам.
- **Личный чат новичок↔директор** (текст + скрины), почти в реальном времени (поллинг 3с), с сохранением.
- **Постоянное хранилище** (JSON-файл) — данные не теряются при перезапуске.
- Фирменный дизайн «Золотые Драконы», логотип, драконы по ролям.
- Задеплоено в интернет (последняя версия с чатом) на `...twc1.net`.
