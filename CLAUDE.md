## Кратко
- Мини-приложение 10-дневной программы адаптации новичков (роли, рефералка, баллы-«Драконы», программа, чат, рейтинги).
- Стек: **Node.js + Express**, данные — **в памяти + JSON-файл** (`data/app-data.json`). **НЕ используй Prisma/базу данных** — из-за них была боль с деплоем.
- Запуск локально: `npm install` → `npm start` → http://localhost:3000
- Деплой: коммит → **GitHub Desktop → Push** → Timeweb (Настройки деплоя → выбрать свежий коммит → Сохранить). git push из CLI НЕ работает.
- Код: https://github.com/natalymakarovasmm-crypto/legkiy-start · Хостинг: Timeweb App Platform (`legkiy-start`) · Домен: app.goldendragon.tech (в процессе).
